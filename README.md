# Rainfall vs. Crop Yield Analysis

## Project Overview
This Power BI project explores historical monsoon rainfall patterns and crop yields across Indian states. It presents the analysis through visualizations intended to support regional comparisons and exploration of patterns in rainfall and agricultural productivity.

## Project Objectives
- Explore rainfall trends over time.
- Compare rainfall and crop-yield patterns across regions.
- Present regional differences through data visualizations.
- Communicate the analysis in a dashboard and exported report.

## Tools
- Microsoft Power BI
- Power Query and DAX, where used in the report

## Project Files
- `Akash_Jadhav_CDPA_B9.pbix` — Power BI report.
- `Akash_Jadhav_CDPA_B9_PDF.pdf` — exported report / project findings.

## How to Explore
1. Open the PDF report to review the exported visualizations and findings.
2. Open the `.pbix` file in Power BI Desktop to explore the report interactively, if you have Power BI Desktop installed.

## Learning Focus
This project provides practical experience with data visualization, time-based trend exploration, regional comparisons, and communicating insights from rainfall and crop-yield data.

## Notes
- This repository documents a completed learning project.
- Findings should be interpreted in the context of the source dataset and the analysis shown in the report.
- Please do not treat visual correlations as proof that rainfall alone causes changes in crop yield.
